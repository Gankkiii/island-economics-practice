### 原子化和去重决策

- 第一章原“延后消费并承担失败风险”拆成当期牺牲与风险两项，分别保留其证据；不把整个因果机制碎成无意义句子。
- 第五章把工资分析中的需求、供给、生产力分别设问，比较时固定其他条件；补入整体降价推论的“货币供应稳定”条件。
- 第十四章把首付对买方还款动机与银行损失缓冲分开；同时区分居住效用和新增生产偿还能力。
- 同章中人物、金额、相同故事的复述不各算知识点。跨章保留的项目，按具体条件或应用区别，并标明若干已有关系，不声称所有观点在语义上互不关联。
- 对年代、统计数字、人物身份不出记忆题；对规范性、政策性论述加作者归属，不把书中立场当作无争议共识。

### 未出题与待核对

- C05-R01：本章末句把通货紧缩称为政治家的朋友，与同章前文批评的方向存在张力。PDF 第 94 页，定位“是被当作经济的头号敌人。这是因为通货紧缩（与通货膨胀相反）是政治家最好的朋友。这一点我们在后面会详细说明。”。
- C15-R01：本章关于经济衰退必要性的措辞需核对版本，不能由这一句话确定必要与非必要边界。PDF 第 225 页，定位“，没有了那些自由现金流，经济也一定会萎缩。为了恢复经济平衡，经济衰退不是必需的，却是必要的。但是，当经济开始收紧时，立法者和经济学家不仅不认为这一过程是多年来银根松动以及过度消费的结果，反而把它当作问”。
- C17-R01：本章末句称需求为增长动力，与前文消费及需求论述存在待澄清的用词关系。PDF 第 248 页，定位“。增加货币供应量固然会鼓励人们消费，但对扩大需求却毫无裨益，而需求才是促进经济增长的真正动力。”。

这三项不擅自修正为“作者本来想说什么”，也不以原文直述的高分覆盖歧义。其余未单列材料主要是情节、重复例证、具体历史数字及既有机制的展开。覆盖结论是本轮编辑复核范围，不是数学证明已穷尽一切可能知识点。

## 出题与复核

每题对应一个可出题知识 ID。题干给出需要的条件，选项提供不同解释；每个错误选项有针对性的区别理由，误解类型为编辑假设，尚无作答数据证明其常见程度。226 题均重写题干与四项，不保留旧题的掌握判定。

- 编辑认知目标：L2 98 题、L3 70 题、L4 58 题。等级不是实测难度。
- 存储顺序的答案：A 56、B 57、C 57、D 56。网站显示时再次随机打乱，并同步对应解析。
- 正确项独自最长：50/226；没有正确项长度超过其他三项最长值的 1.7 倍的题目。长度检查不能证明选项已无措辞线索。
- 正文、四项、逐项解析、原文定位均进行了编辑复核。遮蔽答案的第二遍作答与拟定答案 226/226 一致；**由同一代理完成，不是独立教师或另一位审题者**。没有声称其满足独立人员复审或心理测量验证。
- 因果、资源约束等主题跨章相关，复习时读解析可能帮助后题。此题库用于学习练习，不宣称具有封闭考试的防泄题能力。
- `accepted` 是本轮编辑分流结果，不是“科学验证通过”。[accepted.json](accepted.json)、[manual_review.json](manual_review.json)、[rejected.json](rejected.json) 分开导出；本轮分别为 226、0、0。待核对的是提取候选，已在上游拦截。

## Skill 好不好用

两份流程适合这个任务：先提取能阻止凭印象出题，单题目标、限定条件和逐项解释也便于审查。但原始脚本只实现了部分检查，不能把脚本退出码当成题目正确性的证明。修复后仍不能自动确认事实、唯一语义答案、干扰项是否真有迷惑性、跨章语义重复或真实难度。这些需要原文审查和后续作答数据。

### 确认并修复的问题

| 位置 | 可复现问题 | 修复 |
| --- | --- | --- |
| MCQ 校验 | 未真正运行附带 Schema，空白题干、数字证据、空解析可通过 | 运行 Draft 2020-12 Schema，并额外拒绝纯空白与规范化重复 |
| MCQ 校验 | 列表答案、错误 validation 类型、字符串分数可直接抛异常 | 先检查结构与类型，错误以诊断和非零退出返回 |
| MCQ 分流 | 硬门失败且分数 20，仍允许 manual_review，与低于 70 拒绝规则矛盾 | 低于 70 统一 rejected；硬门不被高分覆盖 |
| MCQ 交付 | 无单独发布检查模式，混合复核记录可能被误当合格题库 | 增加 `--accepted-only`，普通模式明确打印处置状态 |
| MCQ 批次 | 空题库、重复 ID/题干缺少批次拦截 | 拒绝空批次，检查 ID 与规范化题干重复 |
| MCQ Schema | skill 要求每维评分理由，Schema 却未要求 | 补充必需的 rating_reasons，更新示例、依赖和测试 |
| 提取分块 | 原程序可输出 1252 字符块，超过目标 1200，且没有原偏移 | 修正边界与重叠，保留 start_char/end_char |
| 提取去重 | 去掉所有标点，把“1.5%”与“15%”当成相同陈述 | 保留数值及逻辑标点，只做保守规范化；语义合并仍人工判断 |
| 提取校验 | Schema 出错后仍访问缺失字段，导致崩溃 | 结构错误先返回，不再继续关系/分数计算 |
| 提取门槛 | 空白引文、84 分记录仍可被 accepted | 检查非空证据、分数门槛和证据状态 |
| 提取完整性 | 未检查章节归属、自引用、已通过点的目标映射 | 新增对应检查，不把关系存在误当关系事实正确 |

以上修复位于传输仓库中相同的 skill 路径，未修改其他项目文件。回归测试 **35 项通过**（出题 23 项、提取 12 项）。两份脚本对本轮知识和题目均通过结构检查；原文引文逐项匹配实际分页文本。
